Your project is a MERN Stack Application:

Frontend: React + Tailwind CSS
Backend: Node.js + Express.js
Database: MongoDB Atlas
Authentication: JWT
API Communication: Axios

The goal:

A platform where students get subjects, resources, roadmaps, career guidance, tests, and AI-based recommendations.

3. Environment Variables (.env)

We created:

server/.env

Example:

PORT=5000

MONGODB_URI=.....

JWT_SECRET=.....
Why?

Sensitive information should not be written directly in code.

Instead of:

mongoose.connect("mongodb password")

we use:

mongoose.connect(process.env.MONGODB_URI)
