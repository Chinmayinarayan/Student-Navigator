# Security Policy

## Supported Versions

We support the current release of Student Navigator. Please ensure your local setup is updated to the latest commit on the `master` branch.

| Version | Supported |
|---------|-----------|
| Latest Master | Release Candidates & Master Branch |

## Reporting a Vulnerability

If you discover a security vulnerability in this project (e.g., exposed endpoints, JWT validation bypass, IDOR bugs, path traversal risks, or credential exposure), **please do not open a public GitHub issue.**

Instead, report the vulnerability privately by contacting the repository owner/author directly.

Please include:
* A detailed description of the vulnerability.
* Clear steps to reproduce the issue (proof-of-concept script, request payloads, or screenshots).
* Impact analysis of the vulnerability.

We aim to acknowledge reports within 48 hours and coordinate a fix quickly.
